# 下一轮：视觉未来与触觉联合预测

状态：设计已整理，以下未来预测代码尚未包含在当前可训练版本中。仓库内v15入口用于已有同帧decoder，不能作为下面各项的实现声明。

## 需要实现的接口

1. 输入截至t的40帧、10Hz主RGB派生特征。目标为未来10帧，保留各通道mask，不跨episode/split。
2. 核实视觉、手部ROI和几何缓存是否读取t之后的帧。改变未来原视频时，过去输入必须不变。离线全片几何不能直接当作合法past-prefix输入。
3. 加入未来时刻query和视觉latent读出。未来视觉target来自冻结encoder，并使用固定空间池化/降维，不让预测和target共同坍塌。
4. 触觉输出保留接触概率与条件幅值。测试仅主RGB派生条件，真实触觉/腕视频/GT pose用于监督或独立额外观测参照。
5. 新关键路径用真实batch验证梯度、参数变化和strict重载后，才开始正式拟合。

## 分阶段实验

| 阶段 | 配置 | 本次变化 |
|---|---|---|
| 1 | B0 / B1 | 全局主视角，对比增加预测手部条件 |
| 2 | J01 / J10 | 固定输入和主体，视觉loss权重0.1 / 1，对照0 |
| 3 | D0 / D1 | 模态独立双流，对比跨流attention |
| 3 | D2 / D3 | D1加预测接触gate，或改变读取方向 |
| 4 | E1 / E2 | 分别测试动态加权或稳定接触损失 |
| 5 | W1 / W2 / R1 | 投影腕、生成腕、真实腕额外观测参照 |
| 6 | B* / Joint / Wrist | 匹配基线，三个种子，一次新测试 |

大骨干冻结，只训练小型投影、动态、融合和读出。首轮设计上限为13次条件筛选，加最多7次正式对照/补种子，共20次。每次不超过10000更新或4小时；按阶段筛选，不必跑满。

## 评价约定

主指标为0.5秒未来相对响应MAE，先episode平均，再任务宏平均。次要报告0.1/1秒、RMSE、接触区MAE、AP/F1、接触起止、峰值误差与计算成本。

拟议目标：对同输入、同结构、同触觉损失的B*，主MAE下降至少5%，AP降幅不超过1个百分点。配对人物/session或episode bootstrap给出区间，另报三个种子的均值与标准差。5%是待验证目标。

既有414train/44val可以用于开发。原44episode确认集已经评估，后续只作已见诊断。需要另外固定新测试cohort；没有新cohort时只报告验证探索结果。不能将窗口同帧误差与未来预测误差直接排名。

## 模块设计来源

- [FeelWorld](https://arxiv.org/abs/2607.24267)：冻结编码器、共享latent动态、接触门控。
- [SPOTS](https://arxiv.org/abs/2304.11193)：专用双流、交叉连接、等参数比较。
- [VT-WAM](https://arxiv.org/abs/2607.02503)：模态expert与非对称attention。
- [TacWAM](https://arxiv.org/abs/2607.28391)：触觉表示与未来目标读取隔离。
- [OmniVTA](https://arxiv.org/abs/2603.19201)：双流生成、动态/幅值监督。
- [PhysCanvas](https://arxiv.org/abs/2610.28613)：统一canvas与模态一致性。

原方法通常有真实触觉历史或机器人条件。面向HumanTouch的main-only改编应单独命名和验证，不能称为官方方法原样复现。
